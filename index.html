About

Quién soy, dónde estoy técnicamente y hacia dónde voy

Foto de perfil

Soy Pablo Barroso González, estudiante de 4º ESO construyendo una trayectoria técnica orientada a software, sistemas y, a largo plazo, ciberseguridad (Red Team / seguridad ofensiva).

Durante años he sido un gran consumidor de contenido técnico en YouTube — horas escuchando sobre desarrollo, sistemas, redes, seguridad. Eso me dio una visión general amplia, pero en paralelo también he tocado y experimentado con varias ramas: electrónica con Raspberry Pi, desarrollo de videojuegos con Unity y C#, desarrollo web, scripting...

El verano antes de 4º ESO di el salto: me tomé Python en serio, aprendí Git y GitHub de cero a un nivel sólido, y empecé con Linux (Zorin OS) — terminal, bash, sistema de archivos, permisos. Ahora, durante 4º ESO, mi foco es consolidar Python y dominar librerías clave (pandas, pathlib, typing...) mientras profundizo en Linux en paralelo. El objetivo: sacar buena nota, pasar a Bachillerato, y si todo va bien, mis padres me compran un buen PC y me pagan el curso de ciberseguridad de Savitar (hack4u.io). Por eso estoy construyendo bases sólidas ahora, en vez de esperar.

Python — Foco principal (4º ESO) Linux / Terminal (Zorin OS, bash) Networking (bases) Cybersecurity (pre-Savitar) Git / GitHub (workflow real) Unity / C# / Web (pasado)

Currently

En qué estoy enfocado ahora mismo

Python — Consolidar y librerías

4º ESO: afianzar el lenguaje y dominar librerías clave — pandas (análisis de datos), pathlib (rutas modernas), typing (tipado estático con pyright/mypy), pytest (testing), argparse/click (CLI). Objetivo: escribir Python idiomático, limpio y tipado, no solo scripts que funcionan.

Linux — Profundizar en paralelo

Desde el verano con Zorin OS: terminal diaria, bash scripting, gestión de paquetes (apt/dnf), sistema de archivos, permisos, systemd (servicios, logs con journalctl), SSH, automatización. Meta: moverme en Linux con soltura, no solo "saber comandos sueltos".

Redes — Fundamentos reales

Modelo OSI/TCP-IP en profundidad, subnetting, DNS, HTTP/HTTPS, TLS, SSH, WireGuard. Práctica con Wireshark/tcpdump para ver qué pasa en la red, no solo teoría. Base necesaria para luego entender seguridad de red.

Ciberseguridad — Base pre-Savitar

Preparando el curso de Savitar (hack4u.io): reconocimiento pasivo/activo, enumeración de servicios, vulnerabilidades web (OWASP Top 10), explotación básica, escalada de privilegios. Laboratorios: TryHackMe, Hack The Box. Objetivo: llegar al curso con base sólida, no desde cero.
